เครื่องมือคนทำมาหากิน

คำนวณภาษี ผ่อนงวด ตั้งราคาขาย ทำเอกสาร ค่าล่วงเวลา ค่าชดเชย และอีกหลายอย่าง ครบ 20 เครื่องมือในเว็บเดียว

คำนวณทันทีใช้บนมือถือได้แก้ตัวเลขได้ทุกช่อง
ภาษีเงินได้รู้ภาษีที่ต้องจ่ายใน 10 วินาทีผ่อนงวดค่างวดบ้าน รถ สินเชื่อตั้งราคาขายตั้งราคาให้เหลือกำไรจริงสร้างเอกสารใบเสนอราคา ใบลา สัญญาเช่าเทียบสินเชื่อข้อเสนอไหนถูกที่สุดจริงVAT / หัก ณ ที่จ่ายบวก ถอด VAT และยอดโอนจริงค่าล่วงเวลาOT และค่าทำงานวันหยุดค่าชดเชยเลิกจ้างอายุงานกับเงินที่ควรได้เลขเป็นตัวอักษรใช้กรอกเช็คและใบเสร็จเป้าหมายออมเงินออมเดือนละเท่าไรถึงเป้าหารค่าอาหารรวมค่าบริการและ VATจุดคุ้มทุนต้องขายกี่ชิ้นถึงไม่ขาดทุนBMI และพลังงานดัชนีมวลกายและแคลอรี่ต่อวันอายุและนับวันอายุเป็นปี เดือน วันค่าไฟเครื่องใช้ไฟฟ้าเครื่องไหนกินไฟเท่าไรค่าน้ำมันเดินทางต่อเที่ยว ต่อเดือน ต่อคนแบ่งเงินรายเดือนสูตร 50/30/20 ปรับได้เปอร์เซ็นต์ ส่วนลดลดซ้อนกี่ชั้นเหลือเท่าไรแปลงหน่วยที่ดินไร่ งาน ตารางวา ตารางเมตรสุ่มรายชื่อจับสลาก แบ่งกลุ่มทีม
ไม่ต้องสมัคร ไม่ต้องติดตั้ง

บอกสูตรให้ตรวจสอบได้

ทุกเครื่องมือมีคำอธิบายวิธีคิดและข้อสมมติ ไม่ใช่กล่องดำ

อ่านก่อนใช้งาน

ผลลัพธ์เป็นการประมาณการเพื่อประกอบการตัดสินใจ ไม่ใช่คำปรึกษาวิชาชีพ ผู้จัดทำไม่รับผิดชอบต่อความเสียหายจากการนำไปใช้ กรุณาตรวจสอบกับแหล่งข้อมูลทางการก่อนใช้จริง

เลือกเครื่องมือตามงานที่ต้องทำ

  • คำนวณภาษีเงินได้ สำหรับมนุษย์เงินเดือนที่อยากรู้ภาษีและวางแผนลดหย่อน
  • คำนวณค่างวดผ่อน บ้าน รถ สินเชื่อส่วนบุคคล พร้อมดูผลของการผ่อนเพิ่ม
  • ตั้งราคาขายออนไลน์ ให้เหลือกำไรหลังหักค่าธรรมเนียมแพลตฟอร์มและโฆษณา
  • สร้างเอกสาร ใบเสนอราคา ใบลา หนังสือรับรองการทำงาน สัญญาเช่า
  • เทียบสินเชื่อ ดูต้นทุนรวมและดอกเบี้ยแท้จริงของสามข้อเสนอ
  • VAT และหัก ณ ที่จ่าย สำหรับฟรีแลนซ์และร้านค้าที่ออกใบเสนอราคา
  • ค่าล่วงเวลา และ ค่าชดเชยเลิกจ้าง สำหรับพนักงานและฝ่ายบุคคล
  • แปลงตัวเลขเป็นตัวอักษรไทย ใช้กรอกเช็คและใบเสร็จ
  • เป้าหมายออมเงิน และ หารค่าอาหาร สำหรับเรื่องเงินในชีวิตประจำวัน
  • จุดคุ้มทุน สำหรับคนทำธุรกิจเล็ก ดูว่าต้องขายกี่ชิ้นถึงไม่ขาดทุน
  • ค่าไฟเครื่องใช้ไฟฟ้า และ ค่าน้ำมันเดินทาง ประเมินค่าใช้จ่ายประจำเดือน
  • BMI และพลังงานต่อวัน กับ อายุและนับวัน
  • แบ่งเงินรายเดือน และ เปอร์เซ็นต์ ส่วนลด สำหรับเรื่องเงินในชีวิตประจำวัน
  • แปลงหน่วยที่ดิน ไร่ งาน ตารางวา และ สุ่มรายชื่อ สำหรับแบ่งกลุ่มและจับสลาก

คำถามที่พบบ่อย

เครื่องมือเหล่านี้ใช้ฟรีจริงไหม?

ใช้ฟรีทั้งหมด ไม่ต้องสมัครสมาชิก เว็บไซต์อาจมีโฆษณาหรือลิงก์พันธมิตรเพื่อเป็นค่าใช้จ่ายในการดูแลเว็บไซต์

ผลลัพธ์เชื่อถือได้แค่ไหน?

เป็นการประมาณการตามสูตรและเกณฑ์ที่อธิบายไว้ในแต่ละหน้า เหมาะสำหรับวางแผนและเปรียบเทียบ ตัวเลขที่ต้องใช้จริง เช่น ภาษีที่ยื่นหรือค่างวดที่ผูกพัน ควรยืนยันกับหน่วยงานหรือผู้ให้บริการอีกครั้ง

ข้อมูลที่กรอกถูกเก็บไว้ไหม?

ไม่ เครื่องมือทำงานในเบราว์เซอร์ของคุณและไม่ส่งตัวเลขที่กรอกไปเก็บ อ่านเพิ่มที่นโยบายความเป็นส่วนตัว

วิธีคำนวณภาษีเงินได้บุคคลธรรมดา

ภาษีคิดจากเงินได้สุทธิ ไม่ได้คิดจากเงินเดือนทั้งก้อน เริ่มจากรายได้ทั้งปี หักค่าใช้จ่าย หักค่าลดหย่อน แล้วนำเงินได้สุทธิไปคิดตามอัตราขั้นบันได

ขั้นบันไดหมายความว่าอัตราที่สูงขึ้นใช้เฉพาะส่วนที่เกินของแต่ละขั้น เช่น เงินได้สุทธิ 501,000 บาท มีเพียง 1,000 บาทส่วนที่เกิน 500,000 ที่โดนอัตรา 15%

ค่าใช้จ่ายและค่าลดหย่อนที่เครื่องมือนี้คิดให้

  • ค่าใช้จ่ายหักเหมาสำหรับเงินเดือนและค่าจ้าง 50% ของเงินได้ ไม่เกิน 100,000 บาท
  • ลดหย่อนส่วนตัว 60,000 บาท และคู่สมรสที่ไม่มีเงินได้ 60,000 บาท
  • บุตรคนละ 30,000 บาท และบุตรคนที่ 2 ขึ้นไปที่เกิดตั้งแต่ปี 2561 ได้เพิ่มอีกคนละ 30,000 บาท
  • เลี้ยงดูบิดามารดาคนละ 30,000 บาท สูงสุด 4 คน
  • ประกันสังคมไม่เกิน 9,000 บาท ประกันชีวิตและประกันสุขภาพรวมกันไม่เกิน 100,000 บาท (ประกันสุขภาพไม่เกิน 25,000) ประกันสุขภาพบิดามารดาไม่เกิน 15,000 บาท
  • กองทุนสำรองเลี้ยงชีพ RMF และประกันชีวิตแบบบำนาญรวมกันไม่เกิน 500,000 บาท ส่วน SSF ไม่เกิน 200,000 บาท และ Thai ESG ไม่เกิน 300,000 บาท
  • ดอกเบี้ยกู้ซื้อที่อยู่อาศัยไม่เกิน 100,000 บาท

เครื่องมือนี้เหมาะกับรายได้ประเภทเงินเดือนและค่าจ้าง ฟรีแลนซ์และคนขายของออนไลน์มีวิธีหักค่าใช้จ่ายต่างจากนี้ ผลลัพธ์จึงเป็นเพียงแนวทางเบื้องต้น เงื่อนไขของแต่ละรายการลดหย่อนตรวจสอบได้ที่ กรมสรรพากร

คำถามที่พบบ่อย

เงินเดือนเท่าไรถึงต้องเสียภาษี?

ดูที่เงินได้สุทธิ ถ้าหลังหักค่าใช้จ่ายและค่าลดหย่อนแล้วไม่เกิน 150,000 บาทจะไม่เสียภาษี หากมีเพียงลดหย่อนส่วนตัวกับค่าใช้จ่ายหักเหมาสูงสุด รายได้ทั้งปีราว 310,000 บาท (ประมาณ 25,800 บาทต่อเดือน) ยังไม่ต้องเสียภาษี ยิ่งมีลดหย่อนมากตัวเลขนี้ยิ่งสูงขึ้น

ภาษีที่คำนวณได้ต่างจากที่บริษัทหักไว้ได้ไหม?

ได้ บริษัทหักภาษี ณ ที่จ่ายจากการประมาณรายได้และลดหย่อนเบื้องต้น เมื่อสิ้นปีต้องยื่นแบบเพื่อคำนวณภาษีจริง ถ้าถูกหักมากกว่าภาษีจริงจะขอคืนได้ ถ้าน้อยกว่าต้องจ่ายเพิ่ม

ลดหย่อนเพิ่มแล้วประหยัดภาษีได้เท่าไร?

ขึ้นกับช่วงภาษีที่เงินได้สุทธิของคุณอยู่ ถ้าอยู่ในช่วง 15% ทุก 10,000 บาทที่ลดหย่อนเพิ่มประหยัดภาษี 1,500 บาท เครื่องมือด้านบนคำนวณตัวเลขนี้ให้ตามข้อมูลที่คุณกรอก

ยื่นภาษีเมื่อไร?

ปกติยื่นภายในสิ้นเดือนมีนาคมของปีถัดไป การยื่นแบบออนไลน์ผ่านเว็บไซต์กรมสรรพากรมักขยายเวลาให้อีกหลายวัน เช่น ปีภาษี 2568 ยื่นออนไลน์ได้ถึง 8 เมษายน 2569 ควรตรวจประกาศของกรมสรรพากรในแต่ละปี

ถ้าเครื่องมือเหล่านี้ช่วยคุณได้ สนับสนุนผู้สร้างได้ตามกำลัง สแกนด้วยแอปธนาคารแล้วใส่จำนวนเงินที่ต้องการ ใช้ฟรีต่อไปได้ไม่ว่าจะสนับสนุนหรือไม่ ขอบคุณครับ

พร้อมเพย์: STUDIO 27F

อยากได้เว็บไซต์หรือเครื่องมือคำนวณแบบนี้สำหรับธุรกิจของคุณ?

STUDIO 27F รับออกแบบและพัฒนาเว็บไซต์ เครื่องมือคำนวณเฉพาะธุรกิจ และหน้าเว็บสำหรับแคมเปญ เล่าโจทย์ให้เราฟังได้เลย

ส่งข้อความหาเรา
ภาษีเงินได้รู้ภาษีที่ต้องจ่ายใน 10 วินาทีผ่อนงวดค่างวดบ้าน รถ สินเชื่อตั้งราคาขายตั้งราคาให้เหลือกำไรจริงสร้างเอกสารใบเสนอราคา ใบลา สัญญาเช่าเทียบสินเชื่อข้อเสนอไหนถูกที่สุดจริงVAT / หัก ณ ที่จ่ายบวก ถอด VAT และยอดโอนจริงค่าล่วงเวลาOT และค่าทำงานวันหยุดค่าชดเชยเลิกจ้างอายุงานกับเงินที่ควรได้เลขเป็นตัวอักษรใช้กรอกเช็คและใบเสร็จเป้าหมายออมเงินออมเดือนละเท่าไรถึงเป้าหารค่าอาหารรวมค่าบริการและ VATจุดคุ้มทุนต้องขายกี่ชิ้นถึงไม่ขาดทุนBMI และพลังงานดัชนีมวลกายและแคลอรี่ต่อวันอายุและนับวันอายุเป็นปี เดือน วันค่าไฟเครื่องใช้ไฟฟ้าเครื่องไหนกินไฟเท่าไรค่าน้ำมันเดินทางต่อเที่ยว ต่อเดือน ต่อคนแบ่งเงินรายเดือนสูตร 50/30/20 ปรับได้เปอร์เซ็นต์ ส่วนลดลดซ้อนกี่ชั้นเหลือเท่าไรแปลงหน่วยที่ดินไร่ งาน ตารางวา ตารางเมตรสุ่มรายชื่อจับสลาก แบ่งกลุ่มทีม

คำนวณค่างวดผ่อนบ้าน รถ สินเชื่อ

เลือกวิธีคิดดอกเบี้ย ดูค่างวด ดอกเบี้ยรวม และตารางผ่อนรายปี ตัวเลขเริ่มต้นเป็นตัวอย่าง แก้ได้ทุกช่อง

ใส่ตัวเลขเพื่อดูว่าปิดหนี้เร็วขึ้นและประหยัดดอกเบี้ยเท่าไร ใช้กับแบบลดต้นลดดอก
ข้อควรทราบก่อนใช้ผลลัพธ์

ค่างวดจริงขึ้นกับสัญญา ดอกเบี้ยที่ปรับเปลี่ยน และค่าธรรมเนียมของผู้ให้กู้ ยืนยันกับผู้ให้กู้ก่อนตัดสินใจกู้

ค่างวดคำนวณอย่างไร

สินเชื่อส่วนใหญ่ เช่น สินเชื่อบ้าน คิดดอกเบี้ยแบบลดต้นลดดอก ดอกเบี้ยแต่ละเดือนคิดจากเงินต้นที่ยังเหลือ ค่างวดจึงคงที่ แต่สัดส่วนเงินต้นเพิ่มขึ้นเรื่อยๆ ส่วนดอกเบี้ยลดลง

ค่างวด = เงินกู้ × r ÷ (1 − (1 + r)−n) โดย r คืออัตราดอกเบี้ยต่อเดือน (ดอกเบี้ยต่อปี ÷ 12) และ n คือจำนวนงวด

ดอกเบี้ยแบบ flat ต่างจากลดต้นลดดอกอย่างไร

แบบ flat คิดดอกเบี้ยจากเงินต้นตั้งต้นตลอดอายุสัญญา แม้ผ่อนไปแล้วเงินต้นลดลง ดอกเบี้ยแบบ flat 3% ต่อปีจึงเทียบเท่าดอกเบี้ยลดต้นลดดอกที่สูงกว่านั้นเกือบเท่าตัว เครื่องมือนี้แปลงให้เป็น ดอกเบี้ยแท้จริงต่อปี (EIR) เพื่อเทียบกับข้อเสนออื่นได้ตรงกัน

ผ่อนเพิ่มช่วยได้อย่างไร

เงินที่ผ่อนเพิ่มจะตัดเงินต้นโดยตรง ทำให้ดอกเบี้ยเดือนถัดไปลดลง ยิ่งเริ่มเร็วยิ่งประหยัดมาก ลองใส่ตัวเลขในช่องผ่อนเพิ่มต่อเดือนเพื่อดูผล ควรตรวจกับผู้ให้กู้ก่อนว่ามีค่าธรรมเนียมหรือเบี้ยปรับกรณีชำระเกินงวดหรือปิดบัญชีก่อนกำหนด

คำถามที่พบบ่อย

ลดต้นลดดอกกับ flat แบบไหนดีกว่า?

เมื่อดอกเบี้ยต่อปีที่ประกาศเท่ากัน แบบลดต้นลดดอกจ่ายดอกเบี้ยรวมน้อยกว่าเสมอ ดูที่ดอกเบี้ยแท้จริงต่อปี (EIR) ซึ่งเครื่องมือนี้คำนวณให้ จะเทียบข้อเสนอต่างวิธีกันได้ตรงที่สุด

ดอกเบี้ยแท้จริงต่อปีคืออะไร?

คืออัตราดอกเบี้ยที่แปลงให้เป็นฐานเดียวกันกับสินเชื่อแบบลดต้นลดดอก คำนวณจากเงินที่ได้รับกับค่างวดที่ต้องจ่ายจริงตลอดสัญญา ใช้เทียบว่าข้อเสนอไหนแพงกว่ากัน

ผลลัพธ์ตรงกับที่ธนาคารคิดไหม?

ใกล้เคียง ธนาคารอาจคิดดอกเบี้ยรายวัน ปัดเศษ หรือมีอัตราดอกเบี้ยต่างกันในแต่ละปี เช่น ดอกเบี้ยคงที่ช่วงแรกแล้วปรับตามตลาด ใช้ผลลัพธ์นี้เพื่อประมาณการและเปรียบเทียบ ตัวเลขจริงยืนยันกับผู้ให้กู้

สูตรตั้งราคาขายให้ได้กำไร

ค่าคอมมิชชัน ค่าธุรกรรม และค่าโฆษณาคิดเป็นเปอร์เซ็นต์ของราคาขาย จึงต้องหารด้วยส่วนที่เหลือ ไม่ใช่บวกเปอร์เซ็นต์เข้าไปตรงๆ

ราคาขาย = (ต้นทุน + ค่าแพ็ก + ค่าส่ง) ÷ (1 − %คอมมิชชัน − %ธุรกรรม − %โฆษณา − %กำไร)

ตัวอย่าง ต้นทุนรวม 130 บาท ค่าธรรมเนียมและโฆษณารวม 14% ต้องการกำไร 20% ของราคาขาย ราคาขายคือ 130 ÷ 0.66 ได้ประมาณ 197 บาท

ใช้ตัวเลขค่าธรรมเนียมอะไร

อัตราค่าธรรมเนียมของแพลตฟอร์มปรับเปลี่ยนได้บ่อยและต่างกันตามประเภทสินค้าและร้านค้า ค่าเริ่มต้นในเครื่องมือเป็นเพียงตัวอย่าง ควรกรอกตามอัตราล่าสุดที่แสดงในศูนย์ผู้ขายของคุณ และอย่าลืมรวมค่าโปรโมชันหรือคูปองที่ร้านออกเอง

กำไรเป็นเปอร์เซ็นต์ของราคาขาย กับ markup ต่างกันอย่างไร

กำไร 20% ของราคาขายหมายถึงเหลือ 20 บาทจากทุก 100 บาทที่ขายได้ ส่วน markup 20% คือบวก 20% เข้าไปบนต้นทุน ได้กำไรน้อยกว่าที่คิด เครื่องมือนี้ใช้ตัวแรก เพราะตรงกับกำไรที่เห็นในบัญชีมากกว่า

ควรรวมค่าส่งในราคาไหม?

ถ้าคุณออกค่าส่งให้ลูกค้า ให้ใส่ในช่องค่าส่งที่คุณออกให้ เพื่อให้ราคารวมต้นทุนส่วนนี้แล้ว ถ้าลูกค้าจ่ายค่าส่งเองไม่ต้องใส่

ตั้งราคาสูงแล้วจะขายไม่ออกไหม?

ใช้ช่องลองตั้งราคาเองเพื่อดูกำไรที่ราคาตลาด ถ้าต่ำเกินไปให้พิจารณาลดต้นทุน ลดงบโฆษณา หรือขายเป็นชุดเพื่อเพิ่มกำไรต่อออเดอร์

ขายของออนไลน์ต้องจดทะเบียนภาษีมูลค่าเพิ่มเมื่อไร?

โดยทั่วไปต้องจดทะเบียน VAT เมื่อมีรายได้จากการขายสินค้าหรือบริการเกิน 1.8 ล้านบาทต่อปี ผู้ที่ยังไม่ถึงเกณฑ์ยังมีหน้าที่ยื่นภาษีเงินได้ตามปกติ ตรวจรายละเอียดกับกรมสรรพากร

ตรวจเงื่อนไข VAT และอัตราหัก ณ ที่จ่ายของรายได้แต่ละประเภทกับกรมสรรพากรหรือนักบัญชีก่อนออกเอกสารจริง
VAT และหัก ณ ที่จ่ายต่างกันอย่างไร
VAT 7% คือภาษีที่ผู้ขายเรียกเก็บเพิ่มจากลูกค้าแล้วนำส่งสรรพากร ส่วนภาษีหัก ณ ที่จ่ายคือภาษีที่ผู้จ่ายเงินหักไว้ล่วงหน้าจากผู้รับ แล้วนำส่งสรรพากรแทน สองอย่างนี้คิดแยกกัน
ราคาก่อน VAT = ราคารวม VAT ÷ 1.07 และ หัก ณ ที่จ่าย = ราคาก่อน VAT × อัตรา ไม่ใช่คิดจากยอดรวม VAT
อัตราหัก ณ ที่จ่ายที่พบบ่อย
  • ค่าบริการและค่าจ้างทำของ 3%
  • ค่าโฆษณา 2%
  • ค่าขนส่ง 1%
  • ค่าเช่าทรัพย์สิน 5%
ผู้จ่ายที่เป็นนิติบุคคลต้องนำส่งภาษีที่หักไว้ผ่านแบบ ภ.ง.ด.3 หรือ ภ.ง.ด.53 ภายในวันที่ 7 ของเดือนถัดไป การยื่นออนไลน์ขยายเวลาได้ ตรวจกำหนดล่าสุดที่ กรมสรรพากร

ภาษีเงินได้รู้ภาษีที่ต้องจ่ายใน 10 วินาทีผ่อนงวดค่างวดบ้าน รถ สินเชื่อตั้งราคาขายตั้งราคาให้เหลือกำไรจริงสร้างเอกสารใบเสนอราคา ใบลา สัญญาเช่าเทียบสินเชื่อข้อเสนอไหนถูกที่สุดจริงVAT / หัก ณ ที่จ่ายบวก ถอด VAT และยอดโอนจริงค่าล่วงเวลาOT และค่าทำงานวันหยุดค่าชดเชยเลิกจ้างอายุงานกับเงินที่ควรได้เลขเป็นตัวอักษรใช้กรอกเช็คและใบเสร็จเป้าหมายออมเงินออมเดือนละเท่าไรถึงเป้าหารค่าอาหารรวมค่าบริการและ VATจุดคุ้มทุนต้องขายกี่ชิ้นถึงไม่ขาดทุนBMI และพลังงานดัชนีมวลกายและแคลอรี่ต่อวันอายุและนับวันอายุเป็นปี เดือน วันค่าไฟเครื่องใช้ไฟฟ้าเครื่องไหนกินไฟเท่าไรค่าน้ำมันเดินทางต่อเที่ยว ต่อเดือน ต่อคนแบ่งเงินรายเดือนสูตร 50/30/20 ปรับได้เปอร์เซ็นต์ ส่วนลดลดซ้อนกี่ชั้นเหลือเท่าไรแปลงหน่วยที่ดินไร่ งาน ตารางวา ตารางเมตรสุ่มรายชื่อจับสลาก แบ่งกลุ่มทีม

ข้อควรทราบก่อนใช้ผลลัพธ์
ผลตอบแทนเป็นสมมติฐาน ไม่ใช่การรับประกันผลตอบแทนจริง และไม่ใช่คำแนะนำการลงทุน การลงทุนมีความเสี่ยง ผู้ลงทุนอาจสูญเสียเงินต้น
ออมแล้วเงินโตเท่าไร
เงินที่ออมทุกเดือนได้ผลตอบแทนทบต้น ยิ่งเริ่มเร็วเงินยิ่งโต เครื่องมือนี้คิดผลตอบแทนทบต้นรายเดือน แสดงเงินที่คุณออมเองแยกจากผลตอบแทน และตารางสะสมรายปี
มูลค่าอนาคต = เงินตั้งต้น × (1+r)n + ออมต่อเดือน × ((1+r)n − 1) ÷ r โดย r คือผลตอบแทนต่อเดือน และ n คือจำนวนเดือน
ข้อควรรู้

ข้อจำกัดความรับผิดชอบ

เราเป็นเพียงผู้รวบรวมลิงก์สินค้า ไม่ได้เป็นผู้ขาย ไม่ได้รับชำระเงิน และไม่ได้จัดส่งสินค้า การสั่งซื้อ การชำระเงิน การรับประกัน การคืนสินค้า และการดูแลหลังการขายเป็นหน้าที่ของร้านต้นทางและแพลตฟอร์มที่คุณซื้อ


ข้อมูลชื่อ รูป และราคา ดึงจากหน้าสินค้าของร้านต้นทาง อาจคลาดเคลื่อน ล้าสมัย หรือสินค้าหมด ผู้จัดทำไม่รับประกันความถูกต้องและไม่รับผิดชอบต่อความเสียหายจากการตัดสินใจซื้อตามข้อมูลในหน้านี้ ตรวจรายละเอียดจริงก่อนสั่งซื้อทุกครั้ง


เว็บไซต์นี้ไม่เก็บข้อมูลส่วนบุคคลของผู้เข้าชม เมื่อคุณกดไปยังร้านต้นทาง ร้านและแพลตฟอร์มนั้นอาจเก็บข้อมูลตามนโยบายของเขาเอง
สำหรับเจ้าของร้าน


จัดการร้าน


ยังไม่ได้ตั้งค่า Firebase ทำครั้งเดียว (ฟรี ไม่ต้องผูกบัตร):
  1. console.firebase.google.com > Add project
  2. Build > Firestore Database > Create database
  3. Build > Authentication > เปิด Email/Password และเพิ่มโดเมนเว็บของคุณใน Authorized domains
  4. กลับมาที่หน้านี้ ล็อกอินด้วยชื่อ STUDIO27F และรหัสผ่านที่ต้องการ ครั้งแรกระบบจะสร้างบัญชีให้เอง
  5. Project settings > Your apps > Web (</>) คัดลอกค่า apiKey, authDomain, projectId, appId
  6. เปิดไฟล์ index.html ด้วยโปรแกรมแก้ข้อความ ค้นหา sx-config วางค่าที่คัดลอก และใส่ owner_email เป็น studio27f@studio27f.app แล้วอัปโหลดใหม่
  7. Firestore > Rules วางข้อความด้านล่าง แล้ว Publish
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /products/{id} {
      allow read: if true;
      allow write: if request.auth != null
        && request.auth.token.email == 'studio27f@studio27f.app';
    }
  }
}

ข้อจำกัดความรับผิดชอบ
